# ✨ Amanda-machine
Conversor de bases numéricas, que permite tranformar valores em qualquer uma das bases, com o tema enrolados, e suas luzes flutuantes.

## Acesse meu projeto: https://amandareys.github.io/Amanda-machine/

## Funcionalidades
- Conversão entre decimal, binário, octal e hexadecimal
- Conversão automática ao digitar

## Como usar 
Digite um número com base da sua escolha em seu campo, e os outros valores serão convertidos automaticamente.
